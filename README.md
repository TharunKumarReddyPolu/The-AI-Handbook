## 📖 About This Handbook

This handbook is a **curated compilation of AI tools, platforms, and learning resources** designed for developers, AI enthusiasts, and professionals looking to leverage artificial intelligence in their work. Whether you're building AI agents, creating content, or mastering prompt engineering, this guide provides:

- 🛠️ **AI Tools & Platforms**: Handpicked AI tools for various use cases
- 📚 **Learning Resources**: Comprehensive courses, guides, and tutorials
- 🤖 **AI Agents**: Tools for building autonomous AI systems
- 🎨 **Creative AI**: Image generation, video creation, and design tools
- 💻 **Development Tools**: Code generation, UI builders, and automation
- 📊 **Specialized Applications**: From trading to technical documentation

## 🛠️ AI Tools & Platforms

### AI Chat & LLM Platforms

Platforms for accessing and comparing various Large Language Models (LLMs):

- **[Design Arena](https://www.designarena.ai/)** - Use various AI models for free
- **[LM Arena](https://lmarena.ai/)** - Compare and benchmark different language models
- **[OpenRouter](https://openrouter.ai/)** - Unified API for multiple AI models
- **[Google AI Studio](https://aistudio.google.com/prompts/new_chat)** - Google's AI playground and API access
- **[NotebookLM](https://notebooklm.google/)** - Google's AI-powered research assistant

### AI Agents & Automation

Tools for building autonomous AI systems and automating workflows:

- **[Browser Use](https://browser-use.com/)** - Browser AI Agent for web automation
- **[Microsoft Playwright](https://github.com/microsoft/playwright)** - Free browser automation (alternative to Browser Use)
- **[Manus](https://manus.im/)** - General-purpose AI agent
- **[GenSpark](https://www.genspark.ai/)** - No-code AI agent builder
- **[CrewAI](https://www.crewai.com/)** - Multi-agent orchestration framework
- **[Meet Emily](https://meetemily.ai/)** - AI assistant for task automation
- **[Relevance AI](https://relevanceai.com/)** - Build and deploy AI agents
- **[General Agents](https://generalagents.com/)** - AI computer autopilot
- **[Zapier](https://zapier.com/)** - Workflow automation with AI integration

### Development & Code Generation

AI-powered tools for software development and UI creation:

- **[Replit AI](https://replit.com/ai)** - Build apps with natural language prompts
- **[Bolt.new](https://bolt.new/)** - Excellent for building UI quickly
- **[Lovable.dev](https://lovable.dev/)** - Create beautiful UIs with AI
  - [Best Practices](https://docs.lovable.dev/tips-tricks/best-practice)
- **[Comfy.org](https://www.comfy.org/)** - Node-based app for generative AI

### Creative & Content Generation

AI tools for creating images, videos, and multimedia content:

- **[HeyGen](https://www.heygen.com/)** - Create AI videos with your avatar
- **[ElevenLabs](https://elevenlabs.io/)** - Advanced text-to-speech and voice cloning
- **[Midjourney](https://www.midjourney.com/home)** - Generate high-quality AI images
- **[Stable Diffusion Web](https://stablediffusionweb.com/)** - Free image generation
- **[Stability AI](https://stability.ai/)** - Image and video generation models
- **[Gamma](https://gamma.app/)** - AI design partner for presentations
- **[Chronicle HQ](https://chroniclehq.com/)** - AI-powered presentation maker

### Productivity & Documentation

Tools for enhancing productivity and creating documentation:

- **[Limitless.ai](https://www.limitless.ai/)** - AI pendant that acts as a second brain
- **[Eraser.io](https://www.eraser.io/)** - AI for technical design and documentation
- **[Feedly](https://feedly.com/)** - AI-curated news feed
- **[Fireflies.ai](https://fireflies.ai/)** - AI meeting assistant and note-taker
- **[Voice Ink](https://tryvoiceink.com/)** - Text-to-speech for Mac
- **[Wisprflow.ai](https://wisprflow.ai/)** - Voice typing alternative (Mac, Windows, iPhone)
- **[GoFullPage](https://chromewebstore.google.com/detail/gofullpage-full-page-scre/fdpohaocaechififmbbbbbknoalclacl)** - Full page screenshot tool

### Specialized AI Tools

Domain-specific AI applications:

- **[Project Astra](https://deepmind.google/models/project-astra/)** - Google DeepMind's multimodal AI
- **[Snap Trader](https://snaptrader.ai/)** - AI for trading and financial analysis
- **[Apify](https://apify.com/)** - Comprehensive web scraping tools
- **[Air.ai](https://air.ai/)** - AI-powered phone calls and conversations

### AI Tool Discovery

Find the right AI tool for any task:

- **[There's An AI For That](https://theresanaiforthat.com/)** - Comprehensive AI tool directory
- **[AIxploria](https://www.aixploria.com/en/)** - Google for AI tools
- **[Awesome AI Tools](https://github.com/mahseema/awesome-ai-tools)** - Curated GitHub repository
