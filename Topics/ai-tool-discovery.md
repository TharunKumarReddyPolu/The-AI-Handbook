# 🔍 AI Tool Discovery

> Find the right AI tool, open-source alternative, or interactive demo for any task. These directories, launchpads, and curated lists help you navigate the fast-moving AI ecosystem.

---

## 🔑 Key Concepts

- **AI Directories** — Searchable databases indexing thousands of commercial and free AI tools by task and role
- **Interactive Demo Hubs** — Platforms like Hugging Face Spaces where you can test newly released open-source models directly in your browser
- **Agent Skill Registries** — Curated catalogs of reusable `SKILL.md` packs and plugins for coding agents like Claude Code, Codex, and OpenClaw

## 💡 Pro Tips

- **There's An AI For That** and **FutureTools** are the best starting points when you want to search by *task* rather than by product name
- Check **Hugging Face Spaces** and **GitHub Trending** weekly if you want to spot viral open-source models and repos days before they hit mainstream newsletters
- Before paying for a commercial AI SaaS tool, search **OpenAlternative** to see if a self-hostable open-source equivalent exists

---

## 🎯 When to Use What

| Need | Best Platform |
|---|---|
| Find an AI tool for a specific job/task | There's An AI For That, FutureTools, Futurepedia |
| Try new open-source models in the browser | Hugging Face Spaces |
| Catch brand-new startup launches | Product Hunt AI, Alternbits |
| Find open-source alternatives to paid tools | OpenAlternative, GitHub Trending |
| Discover skills for coding agents | Agent Skills (`skills.rest`), Awesome Agent Skills |
