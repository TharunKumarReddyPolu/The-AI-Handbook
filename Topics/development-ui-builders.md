# 🏗️ Development & UI Builders

> AI-powered tools, SDKs, and platforms for rapid application and UI development. Go from idea to working full-stack app in minutes.

---

## 🔑 Key Concepts

- **Prompt-to-App Builders** — Browser environments (like v0, Lovable, Bolt) that generate, preview, and deploy full-stack web apps from natural language
- **Structured Outputs** — Constraining LLM responses to strict type-safe schemas (Pydantic/Zod) so application code never breaks on malformed JSON
- **AI SDK** — Provider-agnostic libraries that standardize streaming text, tool calls, and generative UI components across models

## 💡 Pro Tips

- **v0** and **Lovable.dev** produce the most polished React/Tailwind UIs — follow Lovable's [best practices guide](https://docs.lovable.dev/tips-tricks/best-practice) for production-ready apps
- **Bolt.new** is the fastest way to scaffold a working prototype in seconds without local setup
- **Vercel AI SDK** + **Instructor** (or **BAML**) is the standard stack when building your own custom AI application in TypeScript or Python
- Use **Remotion** paired with an AI coding agent to generate animated product launch videos programmatically

---

## 🎯 When to Use What

| Need | Best Tool |
|---|---|
| React / Next.js UI generation | v0 by Vercel, Google Stitch |
| Full-stack app from prompts | Lovable.dev, Bolt.new, Replit AI |
| Building custom TypeScript AI apps | Vercel AI SDK, Google Genkit |
| Guaranteed JSON / typed LLM outputs | Instructor, BAML |
| Programmatic video from code | Remotion |
