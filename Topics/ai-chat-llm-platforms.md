# 💬 AI Chat & LLM Platforms

> Platforms for accessing, comparing, and benchmarking Large Language Models. Whether you want to chat with an AI, compare model outputs side-by-side, or access models via API — these tools have you covered.

---

## 🔑 Key Concepts

- **LLM (Large Language Model)** — AI trained on massive text data to understand and generate human language
- **API Gateway** — A unified endpoint to access multiple AI models through a single integration
- **Benchmarking** — Comparing AI models on standardized tasks to evaluate performance

---

## 🛠️ Tools & Platforms

| Tool | Description |
|---|---|
| **[Google AI Studio](https://aistudio.google.com/prompts/new_chat)** | Google's AI playground and API access |
| **[NotebookLM](https://notebooklm.google/)** | Google's AI-powered research assistant |
| **[OpenRouter](https://openrouter.ai/)** | Unified API gateway for multiple AI models |
| **[GetMulti.ai](https://getmulti.ai/)** | Every AI model side by side for comparison |
| **[Design Arena](https://www.designarena.ai/)** | Use various AI models for free |
| **[LM Arena](https://lmarena.ai/)** | Compare and benchmark different language models |
| **[Perplexity Model Council](https://www.perplexity.ai/hub/blog/introducing-model-council)** | Where AI models debate to give you an answer |
| **[ChatGPT](https://chat.openai.com/)** | OpenAI's flagship AI chatbot with deep research and voice mode |
| **[Claude](https://claude.ai/)** | Anthropic's AI assistant — superior writing, reasoning, and code |
| **[Google Gemini](https://gemini.google.com/)** | Google's AI assistant integrated with Workspace ecosystem |
| **[Perplexity](https://www.perplexity.ai/)** | AI-powered search engine with real-time cited answers |

---

## 💡 Pro Tips

- **Use OpenRouter** if you want to try multiple models without creating separate accounts
- **NotebookLM** is excellent for deep research — upload your own documents and get AI-grounded answers
- **LM Arena** runs blind comparisons — great for unbiased model evaluation
- **Perplexity** is the go-to for research queries that need real-time, cited sources

---

## 🎯 When to Use What

| Need | Best Tool |
|---|---|
| General chat & writing | ChatGPT, Claude, Gemini |
| Research with citations | Perplexity, NotebookLM |
| Model comparison | GetMulti.ai, LM Arena, Design Arena |
| API access for developers | Google AI Studio, OpenRouter |
