## 🤝 How Can I Contribute?

### Our Pledge

We welcome contributions from developers, AI enthusiasts, and anyone passionate about AI tools and resources.

- Add new AI tools and platforms
- Update existing tool information
- Add new learning resources
- Improve documentation
- Report broken links
- Suggest new categories

### You're Awesome If...

1. You see something new (tools, resources, courses, etc.)
2. Follow the repository's style
3. Explain the benefit of your addition
4. Make a Pull Request (instructions below!)

### Ways to Contribute

1. **Add New Tools** - Found a great AI tool? Add it to the appropriate category!
2. **Update Tool Information** - Has a tool changed? Update its description or URL.
3. **Add Learning Resources** - Share courses, tutorials, or guides you found helpful.
4. **Improve Structure** - Suggest better ways to organize the content.
5. **Fix Broken Links** - Found a dead link? Replace or remove it.
6. **Add Descriptions** - Enhance tool descriptions with more details.

## 📝 Content Contribution

### Adding a New AI Tool

When adding a new tool to the README.md, please follow this format:

```markdown
- **[Tool Name](https://tool-url.com)** - Brief description of what the tool does
```

**Example:**

```markdown
- **[ChatGPT](https://chat.openai.com/)** - Conversational AI powered by GPT-4
```

### Adding a Learning Resource

For courses or tutorials:

```markdown
- **[Course/Resource Name](https://course-url.com)** - Brief description of what you'll learn
```

**Example:**

```markdown
- **[Prompt Engineering Masterclass](https://example.com)** - Comprehensive guide to crafting effective AI prompts
```

## 🎨 Style Guidelines

### Markdown Style

- Use proper heading hierarchy (`##`, `###`, etc.)
- Use **bold** for emphasis on important terms
- Use bullet points (`-`) for lists
- Use code blocks for code snippets
- Add emojis sparingly for visual appeal

### Writing Style

- Keep descriptions concise (1-2 sentences)
- Use active voice
- Be clear and direct
- Avoid marketing language
- Focus on functionality and use cases

## 💬 Commit Messages

Write clear and descriptive commit messages:

### Good Examples:

```bash
git commit -m "Add Anthropic Claude to LLM platforms"
git commit -m "Update HeyGen description and pricing info"
git commit -m "Fix broken link to DeepLearning.AI course"
git commit -m "Add new category: AI Security Tools"
```

### Bad Examples:

```bash
git commit -m "Update"
git commit -m "Fixed stuff"
git commit -m "Changes"
```

### Format:

- Use present tense ("Add feature" not "Added feature")
- Be specific about what changed
- Keep it under 72 characters

## 🔄 Pull Request Process

### 1. Before Submitting

- ✅ Ensure all links are working
- ✅ Check for typos and formatting
- ✅ Follow the style guidelines
- ✅ Place content in the right category
- ✅ Update Table of Contents if needed

### 2. Submitting

1. Push your changes to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```

2. Go to the original repository
3. Click "New Pull Request"
4. Select your fork and branch
5. Fill in the PR template:
   - **Title**: Brief description of changes
   - **Description**: Detailed explanation
   - **Type of Change**: Bug fix, new feature, etc.

### 3. After Submitting

- Respond to reviewer comments
- Make requested changes
- Keep the PR updated
- Be patient and respectful

## 📚 Topic Guidelines

### When Adding AI Tools

Consider these factors:

1. **Relevance** - Is it genuinely useful for AI development/work?
2. **Quality** - Is it a well-built, reliable tool?
3. **Accessibility** - Can others easily access and use it?
4. **Uniqueness** - Does it offer something different?
5. **Active Development** - Is it maintained and updated?

### Categories for AI Tools

Place tools in the most appropriate category:

- **AI Chat & LLM Platforms** — Language model access and comparison
- **AI Agents & Automation** — Autonomous systems and workflow automation
- **AI Coding Assistants** — Code-focused AI tools and IDE integrations
- **Development & UI Builders** — Rapid app and UI development
- **Creative & Content Generation** — Image, video, audio, presentations
- **Productivity & Knowledge Management** — Work enhancement and knowledge tools
- **AI Wearables & Hardware** — Physical AI devices
- **AI for Business & Commerce** — Trading, ads, e-commerce
- **Specialized AI Tools** — Domain-specific applications
- **AI Tool Discovery** — Finding AI tools
- **MCP Ecosystem** — Model Context Protocol tools
- **Run AI Locally** — Local/on-device AI tools
- **Open Source Highlights** — Notable open-source AI repositories
- **AI Glossary** — Term definitions
